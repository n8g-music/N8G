# N8G Symbol Bible

> *The language beneath the language. Every symbol has meaning. Every mark has memory. Nothing is decoration.*

---

## 0. About the Symbol System

N8G's symbols are not a logo system. They are a language — an expandable visual vocabulary that carries meaning across releases, across stages, across time. Each symbol is a vessel: it holds a concept, and when combined with others, it tells a story that words alone cannot.

The system is built from six categories, each a dimension of the N8G universe:

| Category | Domain | Foundational Question |
|----------|--------|----------------------|
| **Numbers** | Structure | How many? In what relation? |
| **Relationships** | Connection | Between whom? In what dynamic? |
| **Time** | Orientation | When? In what direction? |
| **Movement** | Energy | How does it move? At what intensity? |
| **Forms** | Shape | What geometry carries the meaning? |
| **States** | Quality | What condition? What atmosphere? |

### Design Principles

1. **Every symbol has a visual form.** No abstract concept exists without a drawn mark.
2. **Every symbol has construction rules.** The proportions, line weights, and spatial relationships are specified — not approximated.
3. **Symbols combine.** A release is not assigned one symbol; it is composed from several, layered and integrated.
4. **The system expands.** Future releases may add symbols, but never remove them. The vocabulary grows; it does not shrink.
5. **Typographic treatment is defined.** How symbols sit with text, how they scale, how they integrate into layouts — all specified here.
6. **No symbol is decorative.** If a symbol appears, it carries the weight of its meaning. No casual use.

## 1. Numbers

Numbers in N8G are not quantities. They are principles. They structure relationships and define the geometry of everything from stage positions to album track counts.

### 1 — Unity / Origin

**Meaning:** The singular. The source before division. The self before relation. The moment of conception. Also: loneliness, incompleteness, the state before the collective forms.

**Visual Form:** A single vertical stroke — a line from top to bottom. Unadorned. The stroke is the height of the symbol field, centred horizontally. Width: 1/8 of the field width.

**Construction:**
```
Field: 1:1.618 (golden ratio rectangle)
Stroke: Centred, full height, width = field-width / 8
Terminals: Flat (not rounded). Clean cut.
```

**Usage:**
- Appears in the N8G mark itself (the "1" of three digits)
- Used in contexts of beginnings: first releases, opening tracks, debut performances
- Never used alone on a release — 1 is the state before relation, and N8G is always relational

**Typography:** The numeral "1" set in primary sans-serif, light weight, tracking +15%. When paired with the symbol, the numeral and the stroke are treated as equivalent — never both present in the same composition.

---

### 2 — Duality / Resonance

**Meaning:** Relation. Call and response. Tension and release. The space between two points where meaning vibrates. Duality is not opposition — it is the condition that makes resonance possible.

**Visual Form:** Two parallel vertical strokes, equal height, spaced apart. The space between is exactly equal to the stroke width. Together they form a gate, a pause, a breath held between two beats.

**Construction:**
```
Field: 1:1.618
Strokes: Two parallel verticals, full height
Stroke width: field-width / 8 each
Spacing: gap between strokes = stroke width
Position: Centred as a pair
```

**Usage:**
- Represents partnerships, duets, collaborations
- Appears in stereo imagery, left/right channel symbolism
- Used when the collective steps outside itself — a feature, a dialogue
- Base symbol for all call-and-response structures

**Typography:** The numeral "2" set in primary sans-serif, light weight, tracking +15%. When the symbol appears, the numeral may sit above it (stacked) or to the left (inline), never below.

---

### 3 — Trinity / Collective

**Meaning:** The number of N8G. The three members. The triangle — the first stable shape. Three points create the first plane surface. Three people create the first society. Three is completion, balance, the minimum number for complexity.

**Visual Form:** Three vertical strokes, equal height, equally spaced. The outer two are identical to the "2" symbol. The centre stroke is anchored between them — the third presence that transforms duality into trinity.

**Construction:**
```
Field: 1:1.618
Strokes: Three parallel verticals, full height
Stroke width: field-width / 10 each
Spacing: equal between all three strokes
Position: Centred as a trio
```

**Usage:**
- The defining number of the collective
- Appears on every release, every stage, every document
- Three-track EPs, three-movement works, three-act visual narratives
- Can be reduced to three copper points (dots) as a minimalist signature

**Typography:** The numeral "3" set in primary sans-serif, light weight, tracking +15%. This is the most-used numeral in the system. The "3" may appear without the stroke symbol where space demands — it carries full symbolic weight on its own.

## 2. Relationships

Relationship symbols define the dynamics between members, between the collective and the listener, between sound and silence.

### You

**Meaning:** The other. The listener. The fourth member. The presence outside the collective that completes it. "You" is not passive — you are addressed directly, included deliberately.

**Visual Form:** A single stroke, shorter than the other symbols in its category — rising from the baseline to approximately 60% of the symbol field height. It tilts slightly (7°) to the right — reaching, not leaning.

**Construction:**
```
Field: 1:1.618
Stroke: Single vertical, height = 60% of field height
Angle: 7° rightward from vertical
Width: field-width / 10
Position: Anchored at baseline, centred horizontally
```

**Usage:**
- Liner notes addressing the listener
- Album dedications
- The side of the stage facing the audience
- Never used where the collective is addressing itself

**Typography:** The word "you" set in serif body face, sentence case, at body size. In symbol compositions, "you" appears in lowercase only, always positioned to the right of the symbol — the reader is always to the right.

---

### Me

**Meaning:** The self in isolation. Rarely used — and when it appears, it signals vulnerability, the moment before connection. "Me" is the voice that speaks when the mask is metaphorically, but never literally, set aside.

**Visual Form:** A single stroke identical to the "1" symbol — but shorter. Height: 40% of the field. Centred. The proportion signals that the self alone is insufficient.

**Construction:**
```
Field: 1:1.618
Stroke: Single vertical, height = 40% of field height
Width: field-width / 10
Position: Dead centre, both axes
```

**Usage:**
- Extremely rare. Reserved for moments of singular voice — a solo instrumental, a spoken passage, a letter to the self.
- Never used on public-facing materials without Creative Director approval.
- Bears the weight of vulnerability; must be handled with care.

**Typography:** The word "me" set in serif body face, lowercase, at body size or smaller. In compositions, "me" sits below the symbol, centred, as a whisper beneath.

---

### Us

**Meaning:** The collective. The three. The relationship that defines N8G. "Us" is the primary relational state — it includes the members and, in certain contexts, extends to include the listener. "Us" is the sound of the mask speaking as one.

**Visual Form:** Three strokes in the "3" configuration, but connected at the base by a horizontal rule. The horizontal grounds the three — they are not separate entities but a single structure.

**Construction:**
```
Field: 1:1.618
Strokes: Three verticals as "3" symbol
Horizontal: A single rule across the base, connecting all three
Horizontal width: full width of the three-stroke group
Horizontal weight: same as vertical stroke width
Position: Centred
```

**Usage:**
- The collective's signature relational symbol
- Appears on all group communications, collective statements
- Used when introducing the three in visual materials
- Can integrate the "You" symbol to its right to form the complete quaternary (Us + You = N8G complete)

**Typography:** The word "us" set in serif body face, lowercase. In compositions, "us" is centred below the symbol. When combined with "you" → "us / you" on one line, separated by a copper rule.

## 3. Time

Time symbols orient the work temporally. They appear in release sequencing, visual narratives, and the spatial language of the stage.

### Past

**Meaning:** What came before. The foundation. The source. Ancestry, tradition, the ground from which the present rises. Not nostalgia — acknowledgment. The past is not a place to return to; it is the material the present is built from.

**Visual Form:** An arc opening to the left — a backward-facing curve. It suggests a vessel half-full, a bowl that has poured out. The leftward orientation signals direction: where we came from.

**Construction:**
```
Field: 1:1
Arc: Quarter-circle, radius = 40% of field width
Orientation: Opening to the left (western reading direction)
Line weight: field-width / 12
Stroke: Open ends, flat cut, not tapered
Position: Centred vertically; the arc's centre sits at field centre
```

**Usage:**
- Vinyl side A labels (Past → Present)
- Beginning of visual sequences
- The left side of the stage in historical/retrospective performances
- Credit sections: "those who came before"

**Typography:** The word "past" set in serif lowercase, positioned beneath the arc. In sequences: Past → Present → Future, connected by copper rules.

---

### Now / Present

**Meaning:** The moment. Full presence. The only time that is real. N8G work is built to be experienced now — not remembered, not anticipated. The present is the anchor of all temporal symbols.

**Visual Form:** A single point — a filled circle. Centred. Complete. It does not gesture; it simply is.

**Construction:**
```
Field: 1:1
Circle: Filled, radius = 15% of field width
Position: Dead centre
Colour: Copper (#B87333) — the only symbol that is always copper when rendered
```

**Usage:**
- Album centre label
- The centre stage position
- The midpoint of any visual sequence
- The default temporal state — when in doubt, the work is in the present

**Typography:** The word "now" or "present" set in sans-serif uppercase, tracking +20%. Positioned below the point. "Now" is preferred; "Present" is used in formal/long-form contexts.

---

### Future

**Meaning:** What comes next. Not prediction — trajectory. The future in N8G is not utopian; it is inevitable. The mask has always been pointed forward. The future is the direction of travel.

**Visual Form:** An arc opening to the right — a forward-facing curve. The mirror of "Past." It suggests an opening, a door not yet entered, a sound not yet heard.

**Construction:**
```
Field: 1:1
Arc: Quarter-circle, radius = 40% of field width
Orientation: Opening to the right
Line weight: field-width / 12
Stroke: Open ends, flat cut
Position: Centred vertically; arc centre at field centre
```

**Usage:**
- Vinyl side B labels (Future)
- End of visual sequences
- The right side of the stage
- Announcements of forthcoming work

**Typography:** The word "future" set in serif lowercase, positioned beneath the arc. Time sequence reads left to right: Past → Present → Future.

## 4. Movement

Movement symbols capture energy states. They appear in visual rhythm contexts, album sequencing, and stage direction.

### Breath

**Meaning:** The fundamental rhythm. Inhale, exhale. The pause that makes the phrase possible. Breath is the slowest movement — the baseline, the rest state from which all other movement departs. It is the silence before the first note and after the last.

**Visual Form:** A single horizontal wave — one cycle of a sine curve, gentle amplitude. It rises, falls, and returns to baseline. The wave is open at both ends: the breath continues.

**Construction:**
```
Field: 4:1 (wide horizontal)
Wave: One full sine cycle
Amplitude: 25% of field height
Line weight: field-height / 6
Orientation: Starts at baseline, rises, falls through baseline, rises to baseline
```

**Usage:**
- Track separators in album sequencing
- The moment before performance begins
- Visual breathing marks between sections of text
- Background texture at 5% opacity for reflective content

**Typography:** The word "breath" set in serif lowercase, tracking +10%. Positioned at the right end of the wave, as if exhaled.

---

### Pulse

**Meaning:** The heartbeat. The steady, repeating foundation. Faster than breath, slower than flow. Pulse is the grid the music is built on — the invisible architecture that the body feels before the mind names.

**Visual Form:** A sequence of short vertical strokes, equal height, equally spaced, across the field. Five strokes minimum. The regularity is the point — pulse is consistency, reliability, the ground.

**Construction:**
```
Field: 4:1
Strokes: 5–9 verticals, equal height (80% of field height), equally spaced
Stroke width: field-height / 8
Spacing: equal to stroke width
Terminals: Flat
```

**Usage:**
- Rhythmic indicators in visual layouts
- The base layer of visual identity for percussion-heavy releases
- Stage lighting cues (pulses of warm light)
- Never varied in weight — pulse does not accent

**Typography:** The word "pulse" set in sans-serif uppercase, tracking +15%. Positioned centred below the stroke sequence.

---

### Flow

**Meaning:** Unbroken movement. Continuity. The river, the current, the line that does not stop. Flow is the fastest movement symbol — it represents the state of performance, the moment when the three are fully in the work and time dissolves.

**Visual Form:** A continuous horizontal line that varies in thickness — swelling from thin to thick and back — across the field. One continuous gesture, no breaks, no angles.

**Construction:**
```
Field: 4:1
Line: Continuous horizontal, varying thickness
Thinnest: field-height / 12
Thickest: field-height / 4
Transitions: Smooth, organic — a hand-drawn quality
Position: Centred vertically
```

**Usage:**
- Across the full width of album gatefolds
- The connecting line between stage positions during performances
- Visual representation of continuous mixes, long-form works
- The line that connects all three time symbols into a single sequence

**Typography:** The word "flow" set in serif lowercase, italic — the only instance where italic is permitted in symbol typography. Positioned at the right end, as if carried by the current.

## 5. Forms

Form symbols are the primary geometric vocabulary. They are the building blocks from which more complex symbols are constructed.

### Circle

**Meaning:** Wholeness. Cycles. The eternal return. The mask's fundamental shape. The circle contains — it holds energy within a boundary. It is the shape of the self before division, the collective before separation.

**Visual Form:** A perfect circle, stroke only (open centre). The line is continuous — no beginning, no end.

**Construction:**
```
Field: 1:1
Radius: 35% of field width
Stroke width: field-width / 10
Centre: Geometric centre of field
```

**Usage:**
- The N8G mark's "8" is constructed from two stacked circles
- Container for other symbols — a circle around the "3" symbol means "the eternal collective"
- Vinyl record form, CD/DVD form, digital icon containers
- Never filled. The centre must remain open — the void that holds potential.

**Typography:** The word "circle" appears only in construction notes and design specifications — never in public-facing material. The circle speaks for itself.

---

### Triangle

**Meaning:** The three. Stability. The first plane. The triangle is the geometry of N8G — three points create surface, three members create the collective, three notes create a chord. The triangle points upward as default: aspiration, lift, the direction of energy.

**Visual Form:** An equilateral triangle, stroke only, pointing upward. The three sides are equal, the three angles are equal — perfect balance in asymmetry.

**Construction:**
```
Field: 1:1.2 (slightly taller than square)
Triangle: Equilateral, stroke only
Side length: 55% of field width
Stroke width: field-width / 12
Position: Centred; apex at 25% from top, base at 75% from top
```

**Usage:**
- Stage formation geometry
- The negative space between the three members
- Album art anchor — the triangle frequently contains other symbols
- Can point down in specific contexts (see: pointing-down variant for "grounding")

**Typography:** Never labelled in public work. The triangle is the most-used form symbol and requires no explanation.

---

### Spiral

**Meaning:** Evolution. The journey inward and outward simultaneously. Growth that returns to origin but never to the same place. The spiral is time made visible — the past is behind on the curve, the future is ahead on the same path.

**Visual Form:** A continuous line that begins at the centre and expands outward, curving smoothly. Not a perfect mathematical spiral — slightly organic, slightly irregular. Hand-drawn quality.

**Construction:**
```
Field: 1:1
Start: Centre point
Rotation: 2.5–3 full rotations
Growth: Consistent expansion, spiral arms widening gradually
Stroke width: Consistent (field-width / 14)
Direction: Clockwise (outward from centre)
```

**Usage:**
- Album art for evolutionary/transformative works
- The symbol for a member's individual arc within the collective
- Vinyl groove representation
- Never reversed (counter-clockwise = regression, decline — not in our vocabulary)

**Typography:** Never labelled. The spiral is self-evident.

## 6. States

State symbols describe conditions — atmospheres, qualities, the "weather" of a piece of work.

### Energy

**Meaning:** The raw current. Vitality without direction — potential that has not yet taken form. Energy precedes movement. It is the state before the first beat, the charged air before the performance begins.

**Visual Form:** Radiating lines from a central point — six to eight strokes, varying lengths, emanating outward. Not symmetrical. Not contained. The lines suggest expansion, emanation, force moving outward.

**Construction:**
```
Field: 1:1
Centre point: Geometric centre
Lines: 6–8 strokes radiating outward
Length: Varying — 30% to 80% of field radius
Stroke width: field-width / 14
Angles: Irregular, organic distribution — not clock-regular
```

**Usage:**
- High-energy tracks, uptempo sections of performances
- The opener of a set — the signal that something is about to happen
- Combined with Pulse for rhythmic intensity
- Never used alone on slow or reflective work

**Typography:** The word "energy" set in sans-serif uppercase, medium weight, tracking +10%. Positioned beneath the radiating centre, slightly offset to the right.

---

### Aether

**Meaning:** The space between. The negative. The silence that holds the sound. Aether is not absence — it is presence at rest. It is the state of the room before you enter, the pause between movements, the quality of attention when nothing is happening but everything is possible.

**Visual Form:** An empty field — a border only, nothing inside. The border is subtle: a hairline rule in copper or charcoal at 30% opacity. The meaning is in the void.

**Construction:**
```
Field: 1:1 or 1:1.618
Border: Hairline rule, 1px equivalent
Opacity: 30%
Colour: Copper (#B87333) or Charcoal (#1A1A1A)
Interior: Empty. Pristine. No elements.
```

**Usage:**
- Album interludes, ambient passages
- The space between sections in visual layouts
- The moment on stage when all three members are still
- Used as a container: when aether surrounds another symbol, it intensifies that symbol's meaning

**Typography:** The word "aether" set in serif lowercase, centred below the field. Tracking +25%. The word must never be larger than 12px in digital or 8pt in print.

---

### Silence

**Meaning:** The end. The pause that is not waiting — it is arrival. Silence in N8G is the state of completion, not the state before beginning. It is earned, not given.

**Visual Form:** A horizontal rule — a single line across the full width of the field. Below it, nothing. The rule is the threshold: above it, sound. Below it, silence.

**Construction:**
```
Field: 4:1
Rule: Full-width horizontal line
Weight: 2px equivalent
Position: At 30% from top of field
Below rule: Empty space (70% of field)
```

**Usage:**
- End of album, end of side, end of performance
- The final frame of any visual sequence
- Never used at the beginning of anything
- When Silence appears, nothing follows it

**Typography:** The word "silence" set in serif lowercase, tracking +30%. Positioned in the empty space below the rule, small, centred. The space around it must be generous — minimum 3x the word's height on all sides.

---

### Rhythm

**Meaning:** Organised movement. Pattern with intention. Rhythm is energy given structure — it is the state of the collective in performance, the three members locked into the same pulse.

**Visual Form:** A repeating pattern of three elements — stroke, space, stroke, space, stroke. The pattern repeats across the field. The strokes are the same height but may alternate in width: thick, thin, thick (the "3" rhythm).

**Construction:**
```
Field: 4:1
Pattern: Three-stroke unit, repeated
Stroke heights: Equal (80% of field height)
Stroke widths: Thick (field-height/6), Thin (field-height/10), Thick (field-height/6)
Spacing: Equal between all strokes
Repeat: Minimum 2 full units across the field
```

**Usage:**
- Percussive tracks, groove-based work
- Visual rhythms in layout: three-column grids, three-image sequences
- The lighting pattern for uptempo performance sections
- Combined with Pulse for driving sections, with Flow for liquid sections

**Typography:** The word "rhythm" set in sans-serif uppercase, medium weight, tracking +12%. Positioned below the pattern, aligned left or right — never centred. Rhythm is directional.

---

### Resonance

**Meaning:** The vibration that continues. What remains after the sound stops. Resonance is the highest state — it is what N8G pursues. A work resonates when it continues to affect the listener after the last note fades.

**Visual Form:** Concentric rings — three circles centred on the same point, expanding outward. Each ring is slightly thinner than the one inside. The outermost ring is the faintest — resonance fading into aether.

**Construction:**
```
Field: 1:1
Rings: 3 concentric circles
Innermost radius: 10% of field width
Middle radius: 25% of field width
Outermost radius: 42% of field width
Stroke weights: Innermost (field-width/10), Middle (field-width/14), Outermost (field-width/20)
Centre: field centre
```

**Usage:**
- The defining symbol of the collective's highest aspiration
- Appears on every album: the closing frame
- The stage backdrop centre — a single point of resonance expanding outward
- Combined with Aether for the collective's quietest, most spacious work

**Typography:** The word "resonance" set in serif lowercase, tracking +20%. Positioned below the outermost ring, centred. This is the only state symbol that may appear in copper alone without charcoal grounding.

## 7. Symbol Composition Rules

### Combining Symbols

Symbols are rarely used in isolation. They combine to form meaning:

**Layering:**
- State symbols form the ground layer (lowest opacity, largest field)
- Form symbols form the middle layer
- Number or Relationship symbols form the top layer (highest contrast, most present)

**Spatial Syntax:**
- **Containment:** A form containing a number = "the eternal three" (circle + 3), "the stable origin" (triangle + 1)
- **Adjacency:** Symbols side by side = sequence or relationship. Read left to right.
- **Stacking:** Symbols one above the other = hierarchy. The upper governs the lower.
- **Intersection:** Two forms overlapping = synthesis, fusion, collaboration. The intersection zone is copper.

**Forbidden Combinations:**
- Silence + Energy (contradiction in terms)
- Past + Future without Present (the bridge is missing)
- Me + Us (the self dissolves in the collective — Me is only for solo contexts)
- Flow + Silence (arrival ends movement)

### Album/Release Symbol Construction

Every N8G release is assigned a symbol composition — a unique combination that represents the work's specific environment.

The composition follows this structure:
1. **Base State:** One state symbol that defines the work's primary atmosphere
2. **Temporal Orientation:** One time symbol that positions the work
3. **Core Form:** One form symbol that gives the work its geometry
4. **Movement Quality:** One movement symbol that defines the energy

*Example: "Resonance + Present + Triangle + Breath" = a reflective, anchored, structurally precise work in a state of restful presence.*

### Layout Integration

- Symbols always appear larger than body text — minimum 2x the cap height of the surrounding type.
- Symbols sit on the same baseline as text when inline — the symbol's visual centre aligns with the x-height of the surrounding serif.
- When a symbol anchors a composition, it commands its own spatial zone: minimum 3x the symbol field's dimensions on all sides.
- Symbols on stage screens are always copper on charcoal, minimum 1/3 of the screen height.

## 8. Expansion Protocol

### Adding Symbols

Future releases may require new symbols. The protocol for adding to the system:

1. **Justify:** The new symbol must express a concept not already covered by an existing symbol.
2. **Define:** Meaning, visual form, construction, usage, and typography — same structure as all existing symbols.
3. **Test Combinations:** How does the new symbol combine with existing ones? Are any forbidden combinations created?
4. **Ratify:** Creative Director approval required.
5. **Document:** Added to this Symbol Bible with version increment and changelog entry.

### Symbol Versioning

Each symbol carries a version number in the construction file (not in public use). The current release defines the active symbol set. Deprecated symbols are never removed from the Bible — they are marked [DEPRECATED] with the reason and the replacement.

### No Removal

Symbols can be deprecated but never deleted. The symbolic vocabulary only grows. What was meaningful once remains meaningful — even if it falls out of active use.
